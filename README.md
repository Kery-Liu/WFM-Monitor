# WFM 价格监控

**warframe.market 的市场挂单 / 紫卡拍卖，到价就提醒你。** 一个常驻托盘的 Windows 桌面工具：设定目标价后不用再刷网页，达标时弹窗、群机器人、邮件三管齐下。

[English Version](./README.en.md) · Windows 10 / 11（64 位） · 免登录 · 数据只存在本机 · 中英双语界面

---

## 它解决什么问题

- 手动刷新网页无法及时发现限时好价。本工具用轮询 + WebSocket 双通道取价，价格达到设定值时自动通知。
- 紫卡拍卖筛选条件多（正/负词条、极性、洗练、段位），网页只能逐页查看。本工具按这些条件订阅拍卖，仅符合条件的拍卖触发通知。
- warframe.market 位于国外，网络不稳定且排障困难。本工具内置 7 层网络自检，逐项检测代理、DNS、API、订单、拍卖、实时推送与限速熔断，并给出处理建议。
- 桌面弹窗在离开电脑后无法及时接收。本工具支持 Windows 桌面通知、企业微信/钉钉 Webhook、SMTP 邮件，可多通道同时启用。

## 特色

- 关键词搜索：ash prime 一套、ash p set、沙皇、kuva zarr 等均可匹配，内置别名与模糊匹配，返回候选与置信度，需人工点选确认。
- 套装拆分：选中套装后可查看并监控其散件。
- 防打扰：通知支持触发冷却、再降阈值、每小时上限、安静时段。
- 走势图：提供官方 48 小时成交数据，目标价与历史中位价同图展示，悬停可查看各时点的价格与成交量。
- 复制喊话：生成游戏内 `/w` 私聊文案，中英文自动切换，带等级的 MOD 自动补等级。
- 邮件远程控制：发送正文为「检查」的邮件，可触发一轮检查并收到价格汇总回信。
- 常驻托盘：关闭窗口不退出监控；支持全局快捷键触发全部检查。
- 界面与主题：中英双语、深浅主题可切换，物品名与跳转链接跟随语言。

## 安装

### 方式一：安装包（推荐）

1. 下载最新安装包 `WFM-Monitor-Setup-1.1.5.exe`（Releases 页面）。
2. 双击运行，按提示选择安装目录（默认 `%LOCALAPPDATA%\Programs\WFM-Monitor`），**不需要管理员权限**。
3. 装完自动启动，桌面与开始菜单会生成「WFM 价格监控」快捷方式。
4. 首次启动会在后台拉取物品库（约 10–30 秒），之后即可搜索添加监控。

> 安装包未购买代码签名证书，首次运行时 SmartScreen 可能提示「未知发布者」，选择「仍要运行」即可。介意的话可以按下方「从源码构建」自己打包。

### 方式二：从源码运行

需要 Node.js 18+：

```bash
npm install
npm start          # Electron 桌面窗口
# npm run web      # 或无 GUI 模式，浏览器打开 http://127.0.0.1:17890
```

> 如果旧的便携版 / 安装版还在托盘里运行，新实例会被单实例锁挡掉（看起来像「启动后还是旧版」）。`启动.cmd` 会自动关闭旧的 `WFM-Monitor.exe`；也可以双击 `查看修复版.cmd`，用独立配置启动，不影响正在运行的旧版。

### 卸载

Windows「设置 → 应用」里卸载「WFM 价格监控」。卸载**不会**删除你的配置与监控目标，如需彻底清空见「数据与隐私」。

## 快速上手

1. 点左上角 **＋ 新建监控**，选「市场挂单」或「紫卡拍卖」。
2. 搜索框输入关键词，**从候选列表里点选**（不点选不会保存，避免选错相近物品）。
3. 填目标价、检查间隔，点「创建监控」。之后交给它就行。

| 你输入 | 会匹配到 |
|---|---|
| `ash prime 一套`、`ash p set` | Ash Prime 一套 |
| `ash p 图`、`ash prime bp` | Ash Prime 蓝图 |
| `沙皇`、`kuva zarr` | 沙皇（紫卡武器） |

支持的口语别名：`p` = prime，`套 / set / 一套` = 套装，`图 / bp / 蓝图` = 蓝图。候选下方有置信度：`exact` 基本可确定，`weak / none` 请一定看清候选再点。搜索武器本体时会提示「你可能想找的是它的紫卡拍卖」。

### 常用参数

| 参数 | 作用 |
|---|---|
| 买入 / 卖出 | 买入 = 盯别人卖的价格（最低价 ≤ 目标价）；卖出 = 盯别人收的价格（最高价 ≥ 目标价） |
| 卖家范围 | `仅游戏中` 可立即交易；`游戏中+在线`、`全部玩家` 范围更宽 |
| 最小挂单数量 | 过滤只卖 1 个的零散单，按套收时好用 |
| 检查间隔 | 每个目标独立计时，默认 60 秒 |
| 连续确认次数 | 设为 2 表示连续两次达标才通知，过滤瞬时挂单 |
| 紫卡词条 | 必含正面词条需**全部满足**，必含负面词条**任选其一** |
| 极性 / 洗练 / 段位上限 | 硬筛选条件，留空不限 |
| 计价方式 | 紫卡可按一口价或当前竞价判定 |

> 全部参数的逐项说明（含远程控制回信格式、快捷键录制、主题与语言细节）见 [使用说明.md](./使用说明.md)。

## 通知与免打扰

在「设置 → 通知」里可同时开启多个通道：

- **Windows 桌面通知**：系统气泡，点击直达对应监控。
- **企业微信 / 钉钉 Webhook**：粘贴群机器人地址即可；钉钉开了「自定义关键词」安全设置时，把关键词填进来，每条通知都会自动带上。
- **邮件（SMTP）**：QQ 邮箱用 `smtp.qq.com:465`，密码填**授权码**；发件人固定为账号，收件人留空即发给自己。

配好后点「发送测试通知」验证。防打扰机制：触发冷却（默认 600 秒）、冷却期内再降 ≥5 白金可突破一次、每小时上限 30 条、安静时段静音。

## 三种「停」的区别

| 操作 | 含义 |
|---|---|
| 全部暂停 | 临时挂起所有采集，恢复后原样继续，不改任何目标的启用状态 |
| 停用某个目标 | 只停这一个，持久生效；「全部检查」「恢复采集」都不会把它唤醒 |
| 全部检查 | 立刻检查所有**启用中**的目标，自动跳过已停用的 |

## 网络问题自查

切到「网络自检」点「开始自检」，会依次检测代理配置、DNS 解析、API 连通、订单接口、拍卖接口、实时推送、限速熔断状态，每项给出「通 / 不通 + 原因 + 建议」。常见错误码：`[proxy]` 代理没开或地址错、`[cloudflare]` 出口 IP 被标记、`[rate_limited]` 超过官方限速、`[too_many_conn]` 并发过高。

本工具**只调用官方 API（api.warframe.market），不抓取网页 HTML**，正常使用不会触发网页人机验证。

## 数据与隐私

- 所有配置、监控目标、事件与价格历史只存在本机 `%APPDATA%\wfm-monitor\`，没有账号、没有遥测、没有上传。
- 删除该目录即恢复出厂状态；「设置 → 恢复默认设置」可只重置参数（含 Webhook 与邮箱授权码）。
- 通知里使用的是**读取瞬间的快照价**，下单前请再核一次。

## 合规提示

官方限速 3 请求/秒，本工具默认 2 请求/秒，请勿把请求间隔调到 340ms 以下。请遵守 warframe.market 的使用条款，仅作个人价格提醒用途。本工具为非官方粉丝作品，Warframe 商标与数据归 Digital Extremes 与 warframe.market 所有。

## 给想改代码的人

技术栈：Electron + 原生 HTML/CSS/JS，无前端框架、无构建步骤，后端逻辑全部在 `src/core`，换 UI 可整体复用。

### 目录与文件职责

| 路径 | 负责什么 |
|---|---|
| `src/main/main.js` | Electron 主进程：窗口、托盘、全局快捷键、系统通知、IPC 白名单 |
| `src/main/preload.js` | 渲染层与主进程之间的桥，只暴露受限 API |
| `src/web/index.html` / `styles.css` | 页面骨架、设计刻度（圆角/字号/间距/投影）与深黑 / 亮白主题变量 |
| `src/web/app.js` | 全部界面逻辑：卡片、表单、走势图、设置页、弹窗 |
| `src/web/i18n.js` / `i18n-dict.js` | 界面翻译引擎与「中文原文 → 英文」词典，主进程通知文案共用同一本词典 |
| `src/web/theme-boot.js` | 首帧上色，避免切主题闪屏 |
| `src/core/app.js` | 组合根：把各层拼起来，对 IPC / HTTP 暴露稳定接口，含网络自检流程 |
| `src/core/config.js` | 默认值、配置读写、恢复出厂 |
| `src/core/http/` | 网络层：限速令牌桶、并发闸、熔断、代理隧道、超时重试、错误分类 |
| `src/core/sources/` | 取数层：市场订单、紫卡拍卖、WebSocket 实时流、物品清单缓存 |
| `src/core/domain/` | 纯函数层：关键词解析（`resolver.js`）与达标判定（`rules.js`），不碰网络 |
| `src/core/engine/` | 调度层：全局节拍（`scheduler.js`）+ 每目标状态机（`monitor.js`），负责冷却去重与实时流分发 |
| `src/core/notify/` | 通知派发：桌面 / Webhook / 邮件，安静时段与全局限流 |
| `src/core/control/` | 邮件远程控制：IMAP 轮询、指令解析、回信编排 |
| `src/core/store/store.js` | JSON + NDJSON 持久化，目标 / 事件 / 历史 / 运行态 |
| `src/core/errors.js` / `logger.js` / `util.js` | 错误分类转人话、内存环形日志、原子写与文本归一化 |
| `src/server.js` | 无 GUI 模式，同一套 core 走 HTTP 接口 |
| `assets/` | 图标与随包物品库快照（首启免等联网） |
| `scripts/` | 打包、出厂校验、图标生成与各项回归脚本 |

### 读代码的顺序与规矩

依赖方向固定为 `http → sources → domain → engine → notify / store`，`app.js` 负责装配，`main` / `web` 只做展示。几条不要破坏的约定：

1. 只调官方 API，别抓网页 HTML；请求最小间隔不得低于 340ms。
2. UI 不直接发请求，一律走 `core`；`domain` 保持纯函数，方便单测。
3. 关键词解析永远返回候选 + 置信度，不静默替换用户输入。
4. 不引入 SQLite 等原生依赖，避免 Electron 打包 ABI 不匹配。
5. 「停用」「全局暂停」「手动检查」是三套独立状态，改动时跑对应回归脚本。
6. 改界面文案后跑 `npm run test:i18n`，英文残留检查会真实启动一次应用。
7. 改 `src/web/styles.css` 或渲染层结构后跑 `npm run test:ui`，54 项断言覆盖刻度、控件交互、气泡、切换过渡与两侧草稿、主题与溢出。

### 常用命令

| 命令 | 用途 |
|---|---|
| `npm start` / `npm run web` | 桌面模式 / 无 GUI 模式 |
| `npm run test:realtime` 等 `test:*` | 实时流、冷却、停用、错误分类、通知、远程控制回归 |
| `npm run test:update` | v1.0.1 回归：改价即时刷新 / 默认快捷键 / Prime 部件图标 / 配置迁移 |
| `npm run test:ui` | 界面样式回归：刻度、控件交互、主题切换、最小窗口无溢出 |
| `npm run audit` | 物品库体检 |
| `npm run seed` | 重建随包物品清单快照 `assets/catalog.seed.json` |
| `npm run pack` | 免 electron-builder 的绿色版目录（`dist/WFM-Monitor-v<版本>`） |
| `npm run dist` | 构建 NSIS 安装包到 `release/v<版本>/`，先跑出厂商检查 |
| `npm run verify:build` | 验收产物：无个人数据、关键文件齐全 |

打包前的 `scripts/preflight-clean.js` 会强制检查：待打包目录无运行态文件、白名单不含 `data/` 等目录、源码无 Webhook key / 邮箱 / 密码残留，任何一项不通过就中断打包。

`npm run dist` 实际执行 `scripts/build-installer.js`：复用本地 Electron 并裁剪语言包 → 构建目录版 → 用 rcedit 写入图标与版本信息 → 生成 NSIS 安装包 → 跑 `verify-build.js` 验收。产物为 `release/v<版本>/WFM-Monitor-Setup-<版本>.exe`（约 73 MB，含完整运行时，无需用户另装 Node）。因此也不需要下载 winCodeSign，无管理员权限的 Windows 上同样能打包。构建产物按版本分目录，新旧版本不会互相覆盖。
